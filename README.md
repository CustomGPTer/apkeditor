# APK Editor

APK Editor X-rays any Android app, then edits its manifest, code, text, colours, icon and files. Remove permissions, adverts and trackers, clone an app, rebuild, sign and install your copy, compare two versions and save a security report. No internet access, no adverts, no account.

Website: https://customgpter.github.io/apkeditor/

Download: https://github.com/CustomGPTer/apkeditor/releases/latest/download/APKEditor.apk
