**First release.** Look inside, edit, clean and rebuild Android apps on your phone, with no internet access.

- App X-ray: privacy score with reasons, permissions in plain English, 90 advertising and tracking kits found offline, open parts, signature schemes and security checks; PDF security report.
- Projects: private copies of installed apps or APK, APKS, XAPK and APKM files; manifest editor; smali code editor with folding, mini-map, bookmarks, regex find and replace and go to definition, plus a Java view; strings, colours and values in every language; any file replaced, added or deleted; search everything.
- Permission remover with Safe / Usually fine / May crash ratings and presets; ad remover with Light, Standard and Strong; tracker remover; Quick edits; icon and name; clone with a new package name; recipes.
- Rebuild, sign (v1 + v2 + v3) and install, with signature conflicts explained; history with undo for one change or a whole tool run; signing keys made, imported and backed up; split-APK merging; compare two APKs; optional app lock.

Needs Android 10 or later. Size 10.0 MB (10,440,929 bytes).
