Release notes

What changed in each version of APK Editor. The newest is at the top.

Version 1.0.1 27 November 2026Latest

  • No APK files inside the app. Android's own resource tables, which the manifest and resource editors use to turn names into numbers and back, are now kept as plain data files instead of the APK files they came in. Some phone security checks treated those files as hidden apps.
  • Nothing else changes: every tool, screen and setting works as before. It installs over 1.0.0 and keeps your projects, keys, recipes and settings.

Version 1.0.0 27 November 2026

  • First release. Look inside, edit, clean and rebuild Android apps on your phone, with no internet access.
  • App X-ray: privacy score with reasons, permissions in plain English, 90 advertising and tracking kits found offline, open parts, signature schemes and security checks; PDF security report.
  • Projects: private copies of installed apps or APK, APKS, XAPK and APKM files; manifest editor; smali code editor with folding, mini-map, bookmarks, regex find and replace and go to definition, plus a Java view; strings, colours and values in every language; any file replaced, added or deleted; search everything.
  • Permission remover with Safe / Usually fine / May crash ratings and presets; ad remover with Light, Standard and Strong; tracker remover; Quick edits; icon and name; clone with a new package name; recipes.
  • Rebuild, sign (v1 + v2 + v3) and install, with signature conflicts explained; history with undo for one change or a whole tool run; signing keys made, imported and backed up; split-APK merging; compare two APKs; optional app lock.

Checking your download

The file for version 1.0.1 is called APKEditor.apk. It is 10.0 MB (10,490,919 bytes). Its SHA-256 checksum is:

063d3c1b7a2b388f80016284136a6a7d7370d771d1bea5aa39df04ebe1e1b9ad

On Windows, run certutil -hashfile APKEditor.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.

If Google Play Protect blocks it

Why it happens. Google Play Protect checks apps installed from outside Google Play. APK Editor opens other apps, changes them, signs them again and installs them. Some harmful apps do those same things, so Play Protect blocks apps that can do them, whatever they actually do with it. It may say "Harmful app blocked" or "This app may be harmful".

What APK Editor actually does. It does not have Android's internet permission, so it cannot go online, send data or download anything. It has no adverts and no tracking. It only changes an app when you tell it to, it always works on a copy, and it never removes licence checks or unlocks paid features.

Check your file first. Make sure the SHA-256 checksum of your download matches the one above, so you know it is the genuine file from this page.

To install it. Open the Play Store, tap your profile picture, then Play Protect, then Settings (the cog). Turn off Scan apps with Play Protect. Install APK Editor, then turn the setting straight back on.

Afterwards. Play Protect may still warn about APK Editor in a later scan. Updates install over the old version in the same way and keep everything you have saved.
